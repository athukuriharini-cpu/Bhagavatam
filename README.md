# Bhagavatam - Sacred Scripture App 🪷

![Bhagavatam Logo](./bhagavatam_logo.png)

A fully self-contained, offline-first web application that acts as a sacred mediator between the user and the Srimad Bhagavatam scripture.

## 🌟 Features

* **Embedded Knowledge Base:** Comes pre-loaded with curated, open-source (CC BY-NC-SA / Public Domain) translations of key Bhagavatam verses. No external PDFs or internet connection required.
* **Smart Search Engine:** Features a custom-built, intelligent local search engine with multiple modes (Smart Match, Exact Phrase, Any Keyword).
* **Keyword Highlighting:** Matches in the text glow with a sacred golden hue for easy reading.
* **Divine Aesthetic:** A beautifully crafted dark theme featuring deep indigo, gold, and purple, complete with an animated particle system and rotating mandala background.
* **Privacy-First:** 100% of the processing happens locally on the user's device. No API calls, no tracking, no data sent to external servers.

## 🚀 Getting Started

Since this is a client-side application with no build steps or server dependencies, getting started is completely effortless.

1. Clone or download this repository.
2. Open the folder.
3. Double-click `index.html` to open it in any modern web browser.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom styling, CSS variables, flexbox/grid, and keyframe animations.
* **Vanilla JavaScript (ES6+):** Application logic, DOM manipulation, and the custom search engine.
* **No Frameworks:** Built purely with native web technologies for maximum performance and zero dependencies.

## 💼 Commercialization & Licensing

This software is designed to be fully commercial-ready. 
* The codebase contains no sensitive environment variables or secrets.
* The embedded scripture text utilizes public domain/open-source translations to avoid copyright infringement of proprietary translations (e.g., BBT).
